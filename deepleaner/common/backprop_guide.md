# 反向传播速通指南

这份小文档结合 `TwoLayerNet` 代码说明反向传播在做什么、公式怎么来的、为什么比数值梯度快。

## 反向传播是什么
- 目的：算出“损失函数对每个参数的偏导数（梯度）”，好让我们更新参数让损失变小。
- 方法：用链式法则在计算图上从后往前传递“梯度信号”。

## 最小例子（单条链）
- 前向：`y = x * w + b`，损失 `L = y`
- 反向：
  - `dL/dy`：由损失定义给出（如果 `L = y`，则 `dL/dy = 1`）
  - `dL/dw = dL/dy * dy/dw = 1 * x`
  - `dL/db = dL/dy * dy/db = 1 * 1`
- 含义：`w` 每增 1，`L` 增 `x`；`b` 每增 1，`L` 增 1。

## 计算图视角
- 计算图节点：加法、乘法、激活等，每个节点有“局部导数”。
- 反向：上游梯度 × 本节点局部导数 = 传给更前面的梯度。
  - 加法节点：上游梯度直接分发。
  - 乘法节点：上游梯度乘以另一个输入。

## 你代码里的 TwoLayerNet（关键形状）
- 输入 `x`: `(B, 784)`
- `W1`: `(784, H)`, `b1`: `(H,)`
- `W2`: `(H, 10)`, `b2`: `(10,)`
- 前向：
  - `a1 = x @ W1 + b1`        → `(B, H)`
  - `z1 = sigmoid(a1)`        → `(B, H)`
  - `a2 = z1 @ W2 + b2`       → `(B, 10)`
  - `y  = softmax(a2)`        → `(B, 10)`
- 损失：`cross_entropy_error(y, t)`

## 反向传播推导（与你的 `gradient` 代码一致）
1) 从损失对 softmax 输出：  
   `dy = y`；`dy[range(B), t] -= 1`；`dy /= B`   （这是 `dL/da2`）
2) 对 `W2, b2`：  
   `dW2 = z1.T @ dy`   `(H, 10)`  
   `db2 = sum(dy, axis=0)`   `(10,)`
3) 传回隐藏层：  
   `dz1 = dy @ W2.T`   `(B, H)`  
   `da1 = dz1 * z1 * (1 - z1)`   （sigmoid 的导数）
4) 对 `W1, b1`：  
   `dW1 = x.T @ da1`   `(784, H)`  
   `db1 = sum(da1, axis=0)`   `(H,)`

## 梯度下降更新
- `params[key] -= learning_rate * grad[key]`
- 用的是“梯度信号”去改“参数”；梯度本身不保留，下一步重新计算。

## 为什么反向传播比数值梯度快
- 数值梯度：每个参数扰动两次 → 约 `2 * 参数数量` 次前向，量级巨大。
- 反向传播：1 次前向 + 1 次反向 → 开销与前向同级，参数多时差距极大。

## 常见困惑澄清
- “梯度去哪了”：梯度只是中间结果，用来更新参数后就丢弃。
- “偏置要不要算梯度”：要，除非你特意冻结。
- “链式法则怎么乘”：上游梯度乘以当前节点对输入的局部导数，沿链相乘/相加。
- “为什么能分摊责任”：导数刻画了“输入微小变化引起输出变化”，链式法则让变化量沿计算路径传递。

## 如何自检正确性
- 用很小的网络 + 小 batch，随机初始化。
- 同时算数值梯度和反向传播梯度，对比差异（常见容差 `1e-4` 级别）。
