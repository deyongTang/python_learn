# 中心差分与偏导数教学案例

本节用最简单的例子说明：什么是中心差分、如何用中心差分计算偏导数。

## 1. 中心差分（数值导数）

给定函数 `f(x)`，在 `x` 处的导数可以用中心差分近似：

```
f'(x) ≈ (f(x + h) - f(x - h)) / (2h)
```

直觉：用左右两侧的变化平均，通常比“前向差分”更稳定。

### 案例 1：f(x) = x^2

真实导数：`f'(x) = 2x`

在 `x = 5` 处，真实导数是 `10`。  
用中心差分（h = 1e-4）：

```
f'(5) ≈ (f(5 + 1e-4) - f(5 - 1e-4)) / (2e-4)
     ≈ (25.00100001 - 24.99900001) / 0.0002
     ≈ 10
```

## 2. 偏导数（多元函数）

多元函数 `f(x, y)` 在某个点的偏导数，用中心差分分别对 x、y 进行微小扰动：

```
∂f/∂x ≈ (f(x + h, y) - f(x - h, y)) / (2h)
∂f/∂y ≈ (f(x, y + h) - f(x, y - h)) / (2h)
```

### 案例 2：f(x, y) = x^2 + x*y + y^2

解析结果：

```
∂f/∂x = 2x + y
∂f/∂y = x + 2y
```

在点 `(x, y) = (1, 2)` 处：

```
∂f/∂x = 2*1 + 2 = 4
∂f/∂y = 1 + 2*2 = 5
```

用中心差分计算，应该接近 4 和 5。

## 3. Python 参考实现

### 3.1 中心差分（单变量）

```python
def numerical_diff(f, x, h=1e-4):
    return (f(x + h) - f(x - h)) / (2 * h)

f = lambda x: x**2
print(numerical_diff(f, 5))  # 接近 10
```

### 3.2 偏导数（多变量）

```python
def f(x, y):
    return x**2 + x*y + y**2

def partial_x(f, x, y, h=1e-4):
    return (f(x + h, y) - f(x - h, y)) / (2 * h)

def partial_y(f, x, y, h=1e-4):
    return (f(x, y + h) - f(x, y - h)) / (2 * h)

print(partial_x(f, 1, 2))  # 接近 4
print(partial_y(f, 1, 2))  # 接近 5
```

## 4. 常见注意点

- **h 不能太大**：误差会变大  
- **h 不能太小**：浮点精度会出问题  
- 一般用 `1e-4` 或 `1e-5` 作为折中
