# 损失函数入门教学文档（零基础版）

本教程从“为什么需要损失函数”开始，解释常见损失函数的含义、适用场景与直觉。默认你不懂机器学习背景。

## 1. 损失函数是什么

损失函数就是：**衡量模型预测“有多不对”的数字**。

- 预测越接近真实答案，损失越小
- 预测越离谱，损失越大

训练的目标就是：**让损失尽可能小**。

## 2. 为什么需要损失函数

没有损失函数，模型就不知道“错在哪”。

损失函数提供一个“方向”：
- 当前预测错多少
- 应该怎么调整参数（方向上）

## 3. 分类 vs 回归

- **分类**：输出离散类别（比如 0~9）
- **回归**：输出连续数值（比如房价）

不同任务使用不同损失函数。

## 4. 回归常用损失

### 4.1 均方误差（MSE）

```
MSE = mean((y_pred - y_true)^2)
```

- 直觉：误差平方后平均
- 优点：惩罚大误差更重
- 场景：回归问题

### 4.2 平均绝对误差（MAE）

```
MAE = mean(|y_pred - y_true|)
```

- 直觉：误差取绝对值再平均
- 优点：对异常值不那么敏感
- 场景：回归问题

## 5. 分类常用损失

### 5.1 交叉熵（Cross-Entropy）

多分类中最常用：

```
Loss = -sum(y_true * log(y_pred))
```

直觉：
- 如果模型对“正确类别”的概率很大，损失就小
- 如果模型对“正确类别”的概率很小，损失就大

### 5.2 二分类交叉熵

```
Loss = - (y*log(p) + (1-y)*log(1-p))
```

- 适合只有 2 类的任务

## 6. softmax + 交叉熵的关系

在多分类中通常是：

1) 模型输出“得分”（logits）
2) 用 softmax 转成概率
3) 用交叉熵衡量正确类别的概率

这几乎是所有分类任务的标准组合。

## 7. 损失函数的直觉例子

假设真实标签是 3：

- 预测概率：`[0.01, 0.02, 0.05, 0.90, ...]`
  - 正确类别 3 的概率是 0.90 → 损失很小

- 预测概率：`[0.30, 0.20, 0.10, 0.05, ...]`
  - 正确类别 3 的概率只有 0.05 → 损失很大

所以损失函数会逼着模型提高“正确类别的概率”。

## 8. 常见疑问

- **损失函数越小越好吗？**
  训练集上越小越好，但还要看验证集，防止过拟合。
- **为什么不用准确率当损失？**
  准确率不可微，模型没法学习“怎么改”。
- **损失一定是正数吗？**
  通常是非负数，0 表示预测完美。

## 9. 和你当前案例的关系

手写数字识别是多分类问题，最常用的是：

- 输出层：softmax
- 损失函数：交叉熵

不过你现在只做推理，所以只需要知道它们的含义即可。
